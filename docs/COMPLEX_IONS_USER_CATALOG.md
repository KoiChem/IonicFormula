# IonicFormula 錯イオンモード・化合物モード追加仕様

既存の IonicFormula に「錯イオン」を追加する。

## 基本方針

難易度区分は以下の2段階とする。

- `standard`：高校「化学」の教科書本文、典型的な反応式、定番試薬などで扱われる可能性が高いもの
- `advanced`：高校化学の知識で理解可能、または実在する錯イオン・錯塩だが、一般的な高校教科書では必須とは言いにくいもの

UI上では、

- 標準 → 初期ON
- 発展 → 初期OFF

とする。

---

# 1. 命名規則

錯イオン・錯塩の名称は現行命名法に統一する。

使用する名称：

- アンミン
- シアニド
- クロリド
- ヒドロキシド
- アクア錯体は今回収録しない

以下の旧名称は**正解として認めない**。

- シアノ → NG
- クロロ → NG
- ヒドロキソ → NG
- アミン → NG

チオスルファト錯体およびチオ硫酸イオンを含む錯体は今回の候補から完全に除外する。

# 5. [Sn(OH)3]- の化合物モードでの扱い

[Sn(OH)3]- は錯イオンマスターには収録する。

一方、

Na[Sn(OH)3]

などは強塩基性水溶液中の化学種として考えることはできるが、Na2[Sn(OH)6] のような高校教材用の代表的な単離錯塩として扱うには適さない。

そのため、

- 錯イオンモード：advancedとして収録
- 化合物モード：現時点では収録しない

とする。

# 6. 出題上の仕様

## 錯イオンモード

最低限、以下の双方向出題を可能にする。

1. 錯イオン式 → 錯イオン名
2. 錯イオン名 → 錯イオン式

将来的には以下も実装可能なデータ構造としておく。

3. 中心金属イオン＋配位子 → 錯イオン式
4. 錯イオン式 → 中心金属の酸化数
5. 錯イオン式 → 配位数

ただし今回の実装範囲に含めるかは既存アプリの構造に合わせて判断する。

## 化合物モード

既存の組成式⇄化合物名出題と同様に、

1. 化学式 → 化合物名
2. 化合物名 → 化学式

を出題できるようにする。

---

# 7. 化学式データの表記

内部データではASCIIベースで保持してよい。

例：

- `[Cu(NH3)4]2+`
- `[Fe(CN)6]4-`
- `K4[Fe(CN)6]`
- `(NH4)2[PtCl6]`

画面表示では既存 IonicFormula のレンダリング規則に従い、

- 原子数・イオン数 → 下付き
- 電荷 → 上付き
- 錯イオン部分 → `[]`
- 多原子イオン・配位子のまとまり → `()`

を正しく表示する。

# 9. 今回収録しないもの

以下は意図的に除外する。

- [Ag(S2O3)2]3-
- その他チオスルファト錯体
- チオ硫酸イオンを配位子とする錯体
- [Cu(H2O)4]2+
- その他アクア錯体

これらを将来の自動追加や候補生成によって復活させないこと。
